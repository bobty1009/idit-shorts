# Privacy Policy（idit-shorts）

最終更新: 2026-11-17

本ポリシーは、GitHub リポジトリ [idit-shorts](https://github.com/bobty1009/idit-shorts) で提供する動画生成・YouTube 投稿用ツール（以下「本アプリ」）における、個人情報およびユーザーデータの取り扱いを説明します。

本アプリは、開発者本人の学習・コンテンツ制作のために使用することを主目的とします。

## 1. 運営者

- アプリ名: idit-shorts
- 連絡先: GitHub リポジトリの Issues、または Google Cloud OAuth 同意画面に記載のサポートメール

## 2. 取得するデータ

本アプリおよび関連する CI（GitHub Actions）は、次のデータを扱うことがあります。

- Google / YouTube の OAuth 認証情報（access token / refresh token）
- アップロード対象の動画ファイルおよびそのメタデータ（タイトル、説明文、タグ、公開設定）
- 処理ログ（レンダリングやアップロード成否などの技術ログ）

本アプリは、上記以外の目的で Google アカウントのプロフィールや連絡先一覧などを収集しません。

## 3. 利用目的

取得したデータは、次の目的にのみ使用します。

- 開発者本人（または明示的に許可したアカウント）の YouTube チャンネルへ動画をアップロードするため
- 動画生成パイプラインの動作確認・障害調査のため

## 4. 保管場所と期間

- OAuth クライアント ID / シークレット / refresh token は、GitHub Actions の **Encrypted Secrets** など、開発者が管理する秘匿領域に保管します
- リポジトリの公開コードにはトークンを含めません
- 生成途中の動画ファイルは CI ランナー上の一時領域に置かれ、ジョブ終了後に破棄されます（必要に応じて短期間の artifact として残す場合があります）
- YouTube にアップロードされた動画の保管・公開設定は YouTube / Google のサービスに従います

不要になった認証情報は、Google アカウントの [アプリのアクセス権](https://myaccount.google.com/permissions) から取り消し、GitHub Secrets から削除できます。

## 5. 第三者提供

開発者は、取得した OAuth トークンや動画メタデータを、販売・貸与・無関係な第三者への提供をしません。

ただし、次のサービスに処理上必要な範囲でデータが送信されます。

- Google / YouTube（OAuth 認証および動画アップロード）
- GitHub（ソースコード管理および Actions による実行）
- VOICEVOX Engine（音声合成。実行環境上でテキストを音声に変換）

各サービスの取り扱いは、それぞれのプライバシーポリシーに従います。

## 6. 利用者の権利

本アプリの認可を行った Google アカウントの所有者は、いつでも次ができます。

- Google アカウント設定から本アプリのアクセス権を取り消す
- YouTube Studio 上でアップロード済み動画を削除・公開設定変更する
- 開発者に対して、保管しているシークレットの削除を依頼する

## 7. 子どもの個人情報

本アプリは、13歳未満の子どもから意図的に個人情報を収集しません。

## 8. ポリシーの変更

本ポリシーは必要に応じて更新します。重要な変更がある場合は、本ページの「最終更新」日付を更新します。

## 9. 問い合わせ

本ポリシーに関する問い合わせは、[idit-shorts Issues](https://github.com/bobty1009/idit-shorts/issues) へお願いします。
